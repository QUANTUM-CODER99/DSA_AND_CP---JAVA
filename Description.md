# DATA STRUCTURES & ALGORITHUM (DSA) + COMPETITIVE PROGRAMMING (CP) - JAVA

Welcome to this repository!
This is a personal yet carefully maintained collection of my **originally solved coding problems in Java**, created with the intention of not just sharing solutions, but also **sharing understanding**.

---

## ✨ Why This Repository Exists

In many coding repositories, solutions are often shared without context — making them hard to learn from unless you already know the idea.
The goal of this repository is different.

🔹 Every solution here is written **from scratch**
🔹 Every problem focuses on the **core idea and intuition**
🔹 Emphasis is placed on **why** a solution works, not just **how**

This repository serves as:

* A **learning resource** for anyone studying Data Structures & Algorithms
* A **revision notebook** for interview preparation
* A **concept reference** for common patterns and problem-solving strategies
* A record of my **problem-solving journey in Java**

---

## 🧠 What You’ll Find Here

* ✅ Clean and readable **Java implementations**
